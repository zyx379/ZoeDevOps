- **文件**：`renderer/pages/Report.tsx`

### 三、SQL 优化与长 SQL 输出（2026-05-20 补充）

#### 1. SQL 优化模式

- **触发**：消息含「优化/性能/执行计划/索引」等关键词
- **Schema**：`buildSchemaContextForSqlOptimize` 提供 SQL 涉及表的完整列+索引，以及全库表目录
- **执行计划**：`sqlExplain.ts` 自动 EXPLAIN（Oracle: DBMS_XPLAN；达梦: EXPLAIN FOR）
- **上下文 SQL**：追问优化时传入面板中的 `contextSql`（发送前暂存，避免清空后丢失）
- **Prompt**：`REPORT_SQL_OPTIMIZATION_PROMPT` 指导结合执行计划改写 SQL

- 报表对话 `max_tokens` 提升至 8192
- 检测截断（`finish_reason=length` / SQL 块未闭合）时自动续写
- 聊天折叠时 **SQL 代码块始终完整展示**（不再随长文本折叠而隐藏）
