## 改造记录（2026-05-20）

### 一、数据查询：查询/排序条件改为弹窗

- **文件**：`renderer/pages/Schema.tsx`、`renderer/components/TableConditionsModals.tsx`
- **行为**：数据查询页工具栏增加「查询条件」「排序条件」按钮，点击后以居中弹窗编辑；关闭弹窗后不占用主界面空间（移除原内联折叠卡片区域）。
- **说明**：保存为模板、添加字段、AND/OR、拖拽排序等逻辑保持不变，仅 UI 承载方式改为 Modal。

### 二、AI 报表优化

#### 1. SQL 严谨性

- **文件**：`main/report/reportSession.ts`
- **系统提示词**：补充 GROUP BY、字面量引号、别名、日期函数、禁止编造列名等规则。
- **试执行自愈**：生成 SQL 后自动 `executeSelect` 试跑；失败时将数据库错误回填给模型再生成一次（最多 1 次修正），减少用户手动报错追问。

#### 2. 追问时 SQL 面板行为

- **文件**：`renderer/pages/Report.tsx`
- **行为**：发送新消息或「重新生成」时，若已有 `currentSql`，立即清空 SQL 面板与查询结果；待本轮 AI 返回并解析出新 SQL 后再显示。
